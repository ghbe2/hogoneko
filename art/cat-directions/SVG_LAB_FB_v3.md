# SVG試作 FB反映 v3

- 「がりがり」は壁をひっかく動作と解釈。体型「がりがり」は変更なし。
- 壁ガリガリ：背面。顔・内耳を隠し、後頭部、背中、左右の前脚、壁の傷を表示。耳カットの左右は後ろ向きに合わせて反転。
- ふみふみ：座り姿。左右の前足をゆっくり交互に上下させ、前足の下にクッションを配置。
- 胴の模様：cat-surface.js に固定の周方向マップを生成。周方向の角度uと首から腰へ向かう座標vから、可視半面を切り出してSVGへ投影。
- 正面0度、横90度、睡眠108度、背中180度。姿勢遷移で角度を補間。白い胸元は脇で腹側の縁へ回り、背面では隠れる。
- 模様の形状・個体seedは姿勢に依存せず固定。胸と腰は同じ模様地図・投影を共有。
- 胴の柄は従来の平面生成から新方式に変更したため、同じ保存seedでも旧版と模様の見え方が変わる。種類・色・個体設定は保持。
- 後頭部は背面用の模様投影。頭全体・脚・尾の完全な3D回り込みまでは行わない。脚と胴の模様接続は引き続き試作段階。

検証：cat-lab-surface.test.cjs で固定模様、角度別の投影差、背中に白い胸元が出ないこと、座ったふみふみ、背面時の顔非表示、姿勢間の個体保持とSVG保存を確認。既存2テストも実行。
