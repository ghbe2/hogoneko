# ホゴネコ — クライアント確認用モック

心とからだを育てる、保護猫との暮らしのブラウザゲーム。

## 実機プレビュー

https://ghbe2.github.io/hogoneko/

GitHub Pages の公開元を `main` ブランチの `/docs` に設定する。
閲覧用パスワードは別途共有。パスワードを知らずにURLを開くと、入口だけが表示される。

これは公開ソースのモック用の簡易閲覧制限であり、機密保護・利用者本人の認証を保証するものではありません。
ゲームのソースはこの公開リポジトリから閲覧・実行できます。公開用のページには暗号化したゲームを格納し、別の無認証ゲームURLは配置しません。

## 更新

ローカル開発は `index.html` を開く。
公開版の生成は、環境変数 `MOCK_VIEW_PASSWORD` に専用の閲覧パスワードを設定してから `node scripts/build-preview.cjs` を実行する。
生成された `docs/` とソースをコミット・プッシュすると、GitHub Pages が更新される。
パスワードはソース・設定ファイル・READMEに記載しない。

セーブはブラウザ内に保存される。PC・スマートフォン・別ブラウザ間では共有されない。
